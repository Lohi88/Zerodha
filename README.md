# Zerodha (Full Stack Trading Platform)

A full-stack web application inspired by Zerodha, designed to simulate core trading platform functionalities such as market viewing, order placement, and portfolio tracking. This project demonstrates integration of frontend, backend, and deployment workflows in a production-like environment.

---

## 🧩 Project Overview

This project replicates key elements of a trading platform UI and backend architecture. It focuses on building a responsive interface and connecting it with REST APIs for handling trading-related operations.

---

## ⚙️ Key Features

- Responsive trading dashboard interface  
- Stock watchlist view  
- Buy and Sell order simulation  
- Portfolio summary section  
- Order tracking system  
- REST API integration between frontend and backend
